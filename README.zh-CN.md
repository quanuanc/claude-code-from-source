> **本仓库仅用于教育目的。** 它不包含 Claude Code 的任何源码——一行都没有。所有代码块都是原创伪代码，用于说明架构模式。本书的目标是帮助工程师理解生产级 AI 智能体是如何构建的，而不是复现或重新分发专有软件。

---

当 Anthropic 通过 npm 发布 Claude Code 时，其中的 `.js.map` source map 文件在 `sourcesContent` 字段里包含了完整的原始 TypeScript。本书正是研究这套架构后的产物：它把其中的模式、权衡和设计决策提炼成一套技术叙事，让任何工程师都能从中学习。

**全书 7 个部分，共 18 章。** 按印刷书估算约 400 页。

每一章都有分层的阅读深度：面向技术负责人的叙事主线，面向实现者的深入小节，以及一个名为 **“应用到你的系统”** 的收尾部分，用来提炼可以迁移到你自己系统里的模式。图表使用 [Mermaid](https://mermaid.js.org/)，可在 GitHub 上原生渲染。

## 让它成立的 10 个模式

如果你只读一部分，读这里：

1. **把 `AsyncGenerator` 作为智能体循环**——产出 `Messages`，返回带类型的 `Terminal`，天然支持背压和取消。
2. **推测式工具执行**——在模型流式生成期间、响应完成之前，启动只读工具。
3. **并发安全批处理**——按安全性划分工具；读操作并行运行，写操作串行运行。
4. **用分叉智能体共享缓存**——并行子智能体共享字节完全相同的提示前缀，节省约 95% 的输入 token。
5. **4 层上下文压缩**——snip、microcompact、collapse、autocompact；从轻到重逐层加码。
6. **基于文件的记忆与 LLM 回忆**——由 Sonnet 旁路查询选择相关记忆，而不是靠关键词匹配。
7. **两阶段技能加载**——启动时只加载 frontmatter，调用时再加载完整内容。
8. **用粘性锁存器稳定缓存**——一旦发送某个 beta header，就不要在会话中途取消设置。
9. **槽位预留**——默认输出上限 8K，命中上限后提升到 64K（在 99% 的请求中节省上下文）。
10. **钩子配置快照**——启动时冻结配置，防止运行时注入攻击。

## 本书是如何完成的

原始材料来自 npm source map 文件。36 个 AI 智能体分四个阶段分析了近两千个 TypeScript 文件：

1. **探索**：6 个并行智能体阅读源码树中的每个文件。
2. **分析**：12 个智能体写出 494KB 的原始技术文档。
3. **写作**：15 个智能体从头重写，将材料组织成叙事章节。
4. **审阅与修订**：3 个编辑审阅者产出 900 行反馈；3 个修订智能体应用所有修正。

从源码提取到最终修订成书，整个过程大约耗时 6 小时。
